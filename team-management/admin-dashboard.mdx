# Admin Dashboard

The Admin Dashboard is the landing view for team and agency plan admins — an overview of your team managers and connected workspaces.

> **Sidebar label:** Admin Dashboard • **Route:** `/admin-dashboard` (admin console)

## What you see

- **Number of Manager** — Active / Pending / Available seats
- **Number of Connected Account** — Connected / Available LinkedIn account slots
- **Credits Consumed** — your team's credit usage

## Setting up your team

Three setup cards guide you (any order — "You'll always have full access to all LinkedIn accounts"):

| Card | Action |
|---|---|
| **Invite Managers** | Invite your team members to join as Managers using the available seats |
| **Add LinkedIn Profiles** | Add LinkedIn accounts using secure connection links |
| **Assign Profiles** | Assign LinkedIn profiles to Managers so they can start engaging |

Buttons: **Invite Account Managers**, **Add More LinkedIn Profiles**, **Assign Profiles**.

## Switching to manager mode

Click **Switch To Manager Console** (top-left) to enter manager mode. As the admin you're also a manager by default — from there you can switch between the LinkedIn accounts you manage. See [Account Assignment](/team-management/account-assignments).
