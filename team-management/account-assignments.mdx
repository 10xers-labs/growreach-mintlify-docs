# Account Assignment

Account Assignment lets you choose **which managers can manage each connected LinkedIn account**.

> **Sidebar label:** Account Assignment • **Route:** `/account-assignments` (admin)

## How it works

The page shows two panels:

- **LINKEDIN ACCOUNTS** — the connected accounts you can assign (e.g. "1 Connected accounts")
- **MANAGERS** — list of managers, each showing how many accounts they have (e.g. "1 Accounts")

Assign accounts to managers, then click **Save**.

<Tip>
  **Admin by default has access to all LinkedIn accounts.** You only need to assign accounts if you want specific managers to manage specific accounts.
</Tip>

## Manager console access

Once assigned, a manager sees exactly what an individual user sees — but scoped to the LinkedIn accounts assigned to them. The manager switches between accounts using the **account switcher** (top-left, e.g. "AC · Account"). See [Admin Dashboard](/team-management/admin-dashboard) and [Linkedin Accounts](/team-management/linkedin-accounts).
