# Linkedin Accounts

Connect and manage the LinkedIn accounts that will be used with GrowReach (admin console).

> **Sidebar label:** Linkedin Account • **Route:** `/linkedin-account` (admin)

## Account slots

Your plan includes a number of **account slots**. Each slot shows:

| Column | What it shows |
|---|---|
| SLOT | Slot number |
| LINKEDIN ACCOUNT | The connected account (or "Available slot") |
| ASSIGNED MANAGER | Which manager this account is assigned to |
| STATUS | Available / Invited / Connected / Disconnected |
| ACTION | Invite / Manage |

A summary bar shows: **Total Slots / Invited / Connected / Disconnected / Available**.

## Inviting a LinkedIn account (blind link)

<Steps>
  1. Under an **Available slot**, click **Invite**.
  2. In the modal, copy the **Invitation Blind Link** — this link is unique to this slot and invitation.
  3. Send the link to the LinkedIn user (manually, or via the optional **Email address** field with **Send Invitation**).
  4. The client opens the link and securely enters their LinkedIn credentials.
  5. The slot status changes to **Connected** once they complete the flow.
</Steps>

Buttons in the modal: **Copy Blind Link** | **Send Invitation** | **Cancel**.

<Tip>
  You can invite multiple slots at once — the invitations are unique per slot.
</Tip>

## Managing a connected slot

Click **Manage** on a connected slot to expand inline actions:

- **Manage Assigned Managers** — assign which managers can use this account
- **Remove Account** — disconnect the account from this slot

<Warning>
  **You can only connect one LinkedIn account per slot.** To add a different account, remove the current one first — removal is permanent for that slot's connection.
</Warning>

## Managing an invited slot

Click **Manage** on an invited slot for: **Send Invitation** | **Copy Blind Link** | **Cancel Invitation**.
