# Account Managers

Account Managers is where you manage the **manager seats** on your team plan.

> **Sidebar label:** Account Manager • **Route:** `/account-manager` (admin)

## Manager seats

Your plan includes a number of **seats**. Each seat shows:

| Column | What it shows |
|---|---|
| SEAT | Seat number |
| MANAGER | Manager name + email |
| STATUS | Active / Pending Invitation / Available |
| ASSIGNED LINKEDIN ACCOUNTS | Accounts the manager can use |

A summary bar shows: **Total Seats / Active / Pending Invitations / Available**.

<Tip>
  **Seat 1** belongs to the **Admin** — marked "Admin can access all LinkedIn accounts". The team admin is also a manager by default.
</Tip>

## Inviting a manager

<Steps>
  1. Under an **Available Seat**, click **Invite Manager**.
  2. Fill in:
     - **Email Address** (required)
     - **Full Name** (required)
     - **Personalized Message** (optional)
  3. Click **Send Invitation**.
</Steps>

Once accepted, the manager can access the GrowReach dashboard and manage the LinkedIn accounts assigned to them.
